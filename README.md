# patient-deduction-accounting-form
# Учёт пациентов (Patients Project)

Приложение с графическим интерфейсом для ведения базы пациентов, расчёта индекса массы тела (ИМТ) и визуализации статистики. 

## Возможности

- **Просмотр данных:** Таблица со списком пациентов (ФИО, возраст, пол, рост, вес, ИМТ).
- **Управление базой:** Добавление, редактирование и удаление записей.
- **Автоматический расчёт:** ИМТ (Индекс Массы Тела) рассчитывается на лету по формуле `вес / (рост в метрах)^2`.
- **Валидация данных:**
  - В поля ФИО можно вводить только буквы и дефис (без цифр).
  - В числовые поля (возраст, рост, вес) можно вводить только цифры.
  - Отчество является необязательным полем.
- **Статистика:** Окно со сводными графиками:
  - Распределение пациентов по полу (круговая диаграмма).
  - Распределение по возрасту (гистограмма).
  - Распределение ИМТ с учётом пола (наложенные гистограммы).
  - Зависимость ИМТ от возраста (точечный график).
- **Сохранение:** Все данные автоматически сохраняются в файл `data.json` и загружаются при старте программы.

## Технологии

- **Python 3.8+**
- **Tkinter** — стандартная библиотека для GUI (входит в Python, отдельно устанавливать не нужно).
- **Matplotlib** — для построения графиков.
- **JSON** — формат хранения данных.
Для создания примера пациентов была использована библиотека Faker
